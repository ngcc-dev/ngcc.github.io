Target: 128-bit · 256-bit · 512-bit

This preview orders each metric independently and orders the leftmost column by the arithmetic mean of those ordinal ranks. Lower values are better. Ties receive their average rank.

Key-generation latency and secret-key size are excluded. Only reference instances assigned to the 128-bit NGCC target and having every metric required by their category are ranked. For public-key schemes, the percentage after each cycle count is the measured share spent in the ICCS placeholder hash functions. For hash functions, the multiplier is relative to ICCS pseudoXOF with the same output width and message length. Security badges show the A (??%) share means that the candidate uses its own symmetric primitives and no ICCS-facing backend was measured. Security badges show the number of active findings at the candidate's highest severity; they do not affect the performance rank.
