Reproducing this NIST report site

The authoritative publication input is ngcc-dev/ngcc-harness (nist/). Its candidate registry pins official NIST archive and specification hashes without checking large ZIP files into Git. Report pages link to compact reproducer scripts where a runtime or mathematical witness exists. The harness fetches the pinned official NIST submission packages when submitted source is needed; its published runners do not depend on a separate research repository.

Maintainers may refresh the normalized snapshot from a local working checkout. That import path is not part of the published data or reproduction interface.

Build the subsite from a checkout of ngcc.github.io:

make -C nist build SOURCE=../../ngcc-harness/nist
make -C nist check SOURCE=../../ngcc-harness/nist

The builder does not read the clock or local Git state. Two clean builds from the same input are byte-identical, and make check verifies this property.
